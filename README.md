# OneBe 定額ホームページサービス

OneBeの定額ホームページ制作・運用LP。静的HTMLで本文と料金を配信し、ファーストビューに9種類の制作サンプルを用意しています。スマホを3D空間の円周上に配置し、横スクロールに連動して位置・向き・奥行きを更新します。ドラッグ・スワイプ・左右キー・拡大表示に対応し、一周後も続けて閲覧できます。自動回転は停止可能で、動きを抑える利用者設定では停止します。

- 公開先：<https://onebe-inc.github.io/homepage/>
- リポジトリ：<https://github.com/OneBe-inc/homepage>
- 相談CTA（全9か所）：<https://lin.ee/rF35Qat>
- 実行環境：Node.js 22、npm

## 開発・確認

```sh
npm ci --ignore-scripts
npm run build
npm run check:aio:static
npm run dev
```

プレビューは `http://127.0.0.1:4173/homepage/` です。編集後は再度 `npm run build` を実行します。

```sh
node scripts/check.mjs --url http://127.0.0.1:4173/homepage/
```

検査は失敗時に終了コード1を返します。環境変数 `REPORT_PATH` に保存先を指定すると、PASS / FAIL / NOT_TESTED / N/A、対象URL、期待値、実測値、証拠、確認日時をJSONに出力します。指定しない場合は標準出力の要約のみです。HTTP検査は上記の公開先と `127.0.0.1` に限定しています。

## 更新箇所

|内容|ファイル|
|---|---|
|プラン・共通サービス内容・FAQ・サンプル・正規URL|`src/data.mjs`|
|HTML、メタ情報、構造化データ、CTA、料金の補足条件|`src/template.mjs`|
|表示・レスポンシブ・アニメーション|`src/styles.css`|
|回転、横移動、拡大、メニュー|`src/main.js`|
|GA4|`src/analytics.js`|
|ロゴ・写真・favicon・OGP|`public/assets/`|
|ビルド・開発サーバー・自動検査|`scripts/`|

`public/index.html`、`public/404.html`、`public/sitemap.xml`、配信用CSS/JavaScriptはビルド成果物です。これらの直接編集は次回ビルドで上書きされます。`public/assets/` 内の画像はGitで管理します。

料金変更時は `plans` の数値に加え、FAQ、初期費用、最低契約期間、対象範囲、メタ説明、料金表示の確認日も確認してください。月額料金のHTMLとJSON-LDは同じ `plans` から生成します。検査側の期待値も、承認済みの新料金へ合わせて更新します。`site.updated` は内容に実質的な変更がある場合だけ変更し、ビルドのたびに進めません。

## 公開手順

1. ビルドと静的検査を実行し、PC・モバイルの表示、横移動・回転停止・サンプル拡大、キーボード操作、FAQ、問い合わせ導線を確認します。
2. GitHubのリポジトリ設定でPagesのSourceを **GitHub Actions** に設定します。
3. 変更を `main` に反映します。`.github/workflows/pages.yml` がビルド・静的検査後、`public/` をGitHub Pagesへ公開します。Actionsから手動実行もできます。
4. デプロイ成功後、公開ページと次のHTTP検査を確認します。

```sh
npm run check:aio:http
```

HTTP検査はトップの200応答、存在しないURLの404/410、HTMLとHTTPヘッダーのindex方針、配信本文、資産応答を確認します。OGP画像は公開URLから取得できることも確認してください。URLを変更する場合は `site.url`、検査のページ台帳・許可ホスト、GA4の本番判定、既存URLへの影響を併せて更新します。

## 計測

GA4測定IDは **`G-21K44SV7K0`** です。HTTPSの `onebe-inc.github.io`、`/homepage/` 配下でのみ読み込み、ローカルプレビューでは送信しません。

## OneBe AISEO構築ルールへの対応

`OneBe-AIO_RULES.md`（v2.0、2026-09-14）の制作基準を適用しています。主要本文の静的HTML化、単一h1と見出し階層、日本語lang、固有メタ情報、自己参照canonical、サイトマップ、404のnoindex、画像alt・寸法、内部リンク・ID、JSON-LDと表示料金の整合を検査します。出力物の仮ドメイン、開発URL、ローカル機密パス、既知の秘密鍵形式も確認します。

次の項目はこの自動検査だけではPASSにしません。確認できる権限と証拠を取得して別途記録してください。

- **NOT_TESTED**：Search Console／Bing Webmaster Toolsの所有権・実効設定・インデックス状況、各検索サービスの管理画面。
- **NOT_TESTED**：実際のBotのアクセス、CDN・WAFを含む到達性。通常のGET成功だけでは証明できません。
- **NOT_TESTED**：検索露出と別に決定する、学習用クローラーの利用方針。
- **NOT_TESTED**：新規公開時の実ユーザーCore Web Vitals、検索・AI経由の成果、外部プロフィールとの整合、GA4管理画面での受信。
- **別途実査**：ブラウザの表示・主要操作・アクセシビリティ・性能、外部問い合わせフォームの送信確認。検証時の結果を記録し、未実施を完了扱いにしません。

**Project Pagesの制約：** robots.txtはホストルートの `https://onebe-inc.github.io/robots.txt` が対象です。`/homepage/robots.txt` を置いても、このプロジェクトに対するクローラー方針の制御にはなりません。ルートを管理するサイト・権限・既存方針を確認して対応し、学習方針を無断で変更しません。サイトマップ送信は所有権確認後に行います。

検査通過は、検索掲載・順位・AI引用・特別な検索表示を保証するものではありません。
